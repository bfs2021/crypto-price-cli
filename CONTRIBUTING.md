# Contributing to crypto-price-cli

Thanks for your interest in contributing!

## Setup

```bash
git clone https://github.com/yunaremaia/crypto-price-cli.git
cd crypto-price-cli
npm install
```

## Development

```bash
npm test       # run tests
npm run lint   # syntax check
```

## Commit style

Use conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`, `security:`.

## Pull requests

- Add tests for new behavior (TDD preferred).
- Ensure `npm test` and `npm run lint` pass.
- Update README if user-facing changes.
